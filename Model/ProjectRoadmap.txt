Layer	Trainable?	Reason
EmbeddingLayer	✅ Yes	Learns the embedding matrix. -- Trainability implemented.
LinearLayer	✅ Yes	Learns weights and biases. -- Trainability implemented.
LayerNorm	✅ Yes	Learns gamma (scale) and beta (shift). -- Trainability implemented.
AttentionHead	✅ Yes	If it owns the query/key/value/output LinearLayers directly, it should expose their parameters (or forward them).
MultiHeadAttention	Usually ✅	It owns the output projection LinearLayer, and likely the attention heads, so it should expose all child parameters.
FeedForwardLayer	Usually ✅	It owns two LinearLayers, so it should expose their parameters.
TransformerBlock	Usually ✅	It owns trainable child layers and should aggregate their parameters.
GeluLayer	❌ No	Pure activation function. No learned parameters.
PositionalEncodingLayer	❌ No	Fixed sinusoidal encoding. Nothing is learned.
CrossEntropyLoss	❌ No	Computes the loss only.
TransformerModel	Not a layer	It orchestrates everything.
